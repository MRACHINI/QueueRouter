opencode — automatic (models and limits stay up to date)

Log in once; opencode then loads every model and alias this key may use, with context limits, each time it starts. Requires a recent opencode (1.19+).

Linux / macOS:

QUEUEROUTER_KEY={{ key }} opencode auth login {{ site_url }}

Windows (PowerShell):

$env:QUEUEROUTER_KEY="{{ key }}"; opencode auth login {{ site_url }}/windows

Then pick a queuerouter/… model with /models in opencode.

opencode plugin (optional add-on, recommended)

Tags opencode's requests with its session and task, so QueueRouter finishes a conversation (and its subagents) before starting new ones and applies run budgets per task; sends title generation at low priority; and loads your models from QUEUEROUTER_KEY (no login needed), keeping the list current while opencode runs (new models and aliases appear by themselves).
