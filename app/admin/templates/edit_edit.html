Find and replace
Python regular expressions: ^ and $ match at each line, (?s) lets . cross lines. In the replacement, \1 or \g<name> is what a group found. A pattern that takes over a quarter of a second on a prompt is skipped (and noted).

Model

The model gets these and the text, and answers with the new text, which replaces it. Its answer is kept: the same text isn't sent again (a different date or folder in it is a different text: use "Only this part" to send just what you want rewritten).

The model reads the prompt by paragraph and answers with edits of its own (find and replace, or a pattern), listed below once made. It reads only paragraphs it hasn't read before, so after the first requests it's rarely asked; it also marks parts that change between requests (a date, a folder) as "keep", so they don't count as new.

Waiting: the request goes on once the model answers (the first time a text is seen). Not waiting, or past the time: the request goes with what's there, and the model's work counts from the next one. A model that fails isn't asked again for a minute.
