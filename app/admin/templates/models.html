Models & aliases

An alias is a stable model name for your apps (e.g. smart, code). QueueRouter rewrites it to the real model before forwarding, so you can switch models here without touching any app. Aliases show up in /v1/models with their target's context size.

Context sizes

How many tokens each model accepts. QueueRouter checks requests against it before queuing, and opencode is told it (so it compacts in time). It comes from the provider's model list; when a provider doesn't say, QueueRouter learns it from the provider's own "too long" error. Set it here by hand to fill a gap or correct a wrong value (applies on every upstream; a plan's context cap still applies on top).
