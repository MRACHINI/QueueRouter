Context sizes

How many tokens each model accepts. QueueRouter checks requests against it before queuing, and opencode is told it (so it compacts in time). It comes from the provider's model list; when a provider doesn't say, QueueRouter learns it from the provider's own "too long" error. Set it here by hand to fill a gap or correct a wrong value (applies on every upstream; a plan's context cap still applies on top).

Thinking levels

Levels opencode offers next to a model (low / medium / high…), so you can choose how much it thinks before answering. They come from the upstream's own model list (OpenRouter states them; ArliAI says whether a model thinks), else from OpenRouter's public list by name. QueueRouter asks each upstream its own way: OpenRouter reasoning.effort, ArliAI and other vLLM servers the chat template's thinking switch (and low/medium/high), OpenAI-style APIs reasoning_effort. Claude's OpenAI-compatible endpoint ignores levels, so none are offered there. Set your own list to correct a model (e.g. none, low, high), or - for no selector; blank goes back to what's detected. opencode shows them through the QueueRouter plugin (opencode 2.x; re-install the plugin once to get this).
