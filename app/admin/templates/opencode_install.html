Run this once on each computer, then restart opencode (terminal version: opencode service restart). It installs the QueueRouter plugin and saves the key in a file beside it, so nothing goes in the environment. The plugin loads every model and alias this key may use and keeps the list current while opencode runs; tags requests with their session and task, so a conversation (and its subagents) finishes before new ones start and run budgets apply per task; sends title generation at low priority; and updates itself.
