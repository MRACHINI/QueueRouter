Answer rules

Checks of an alias's answers by text, a list of words or a pattern. Attach rules in order to an alias (alias editor, Answer check): the first rule that's on and matches decides: fail the answer (the next model answers), pass it, pass it but run the free checks, or ask the alias's taggers. A rule that tags gives the answer a tag (Taggers page) and decides nothing. With none deciding, the built-in refusal phrases run, then the taggers. A rule watching decides nothing: when the taggers read an answer it matched, whether what they decided agreed is counted. An alias's rule maker can propose rules from the answers its taggers decided. Rules cost nothing; the last model's answer isn't checked.
