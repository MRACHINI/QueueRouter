Answer rules

Checks of an alias's answers by exact text or a pattern, for refusals or anything else you don't want to pass on. Make a rule here, then attach rules in order to aliases (alias editor, Answer check). An alias tries its rules first, then the built-in refusal phrases (its "refused" trigger), then its checker model if it has one: the first rule that matches fails the answer, and the same request goes to the alias's next model. Rules cost nothing and take no time; the last model's answer isn't checked (nothing is left to fall back to).
