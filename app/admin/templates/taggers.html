Taggers

A tagger is a model that reads an alias's answer and gives it tags from a list you make here (e.g. tech, medical, doing-work). Run taggers in order from an alias's editor (Answer check): after each one the alias decides by the tags so far: pass the answer, fail it (the same request goes to its next model), go on to the next tagger, or jump to a later one. A rule can give a tag too, for nothing (Rules page). The Requests page shows each answer's tags and can show only the requests with a tag.
